# BridgeAid logo review

Two minimal directions were considered:

1. **Span and path (selected).** Two sturdy supports carry one clear bridge arc,
   while a short center path moves upward through the opening. The mark remains
   recognizable at favicon size, communicates access and forward movement, and
   uses one practical BridgeAid green.
2. **Linked piers.** Two offset piers connected by a straight deck created a
   compact “BA” monogram. It was legible, but the letterform felt more like a
   software badge than a bridge to real-world help.

The selected span-and-path concept avoids gradients, badges, location pins,
hearts, hands, and decorative detail. The horizontal wordmark uses a system
sans-serif fallback, while the app header keeps “BridgeAid” as live text for
responsive readability and accessibility.
